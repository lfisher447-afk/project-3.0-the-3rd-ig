## ⚡ 02. PLATFORM OVERVIEW

Spotui Web is the client-side workstation for audio routing, private vault storage, streaming media decompression, and unrestricted web tunneling. Built from the ground up for modern browser runtimes, it merges desktop-grade digital signal processing with low-level WebAssembly packet acceleration.

### 🧩 Architectural Separation

```
                       ┌─────────────────────────────────────┐
                       │       SPOTUI UNIFIED ECOSYSTEM      │
                       └──────────────────┬──────────────────┘
                                          │
            ┌─────────────────────────────┴─────────────────────────────┐
            ▼                                                           ▼
 ┌───────────────────────────┐                               ┌───────────────────────────┐
 │       SPOTUI WEB 3.0      │                               │       SPOTUI ANDROID      │
 ├───────────────────────────┤                               ├───────────────────────────┤
 │ • React 19 + TypeScript   │                               │ • Native Kotlin / Java    │
 │ • Web Audio 10-Band DSP   │                               │ • Media3 / ExoPlayer      │
 │ • Real .wsm WASM Streams  │                               │ • Android Keystore Vault  │
 │ • Service Worker Proxy    │                               │ • Background Audio Engine │
 │ • Web Crypto PBKDF2/AES   │                               │ • Hardware Audio Routing  │
 └───────────────────────────┘                               └───────────────────────────┘
```

> [!NOTE]
> **Spotui Web** is completely independent and un-sandboxed from Android-specific hardware dependencies. It relies exclusively on W3C standard Web APIs (Web Audio, WebAssembly, Web Workers, IndexedDB, and Web Crypto) for maximum cross-platform agility.

## 🧬 05. REAL `.wsm` WEBASSEMBLY STREAMING PIPELINE

Spotui Web introduces real compiled `.wsm` (**WebAssembly Stream Module**) binaries to process byte-level packet transformations directly inside the browser's WASM linear memory:

```
[ Incoming Stream / Proxy Packet ]
                │
                ▼
      ┌──────────────────┐
      │  sw-proxy.js     │  ◄── Client-side Service Worker request interceptor
      └────────┬─────────┘
                │
                ▼
      ┌──────────────────┐
      │  wsm-loader.ts   │  ◄── Dynamic WebAssembly binary compiler & memory allocator
      └────────┬─────────┘
                │
       ┌────────┴────────┬─────────────────┐
       ▼                 ▼                 ▼
┌──────────────┐ ┌──────────────┐ ┌─────────────────┐
│ proxy-engine │ │ tunnel-core  │ │ stealth-crypto  │
│    .wsm      │ │    .wsm      │ │      .wsm       │
│ Packet & CSP │ │ WS Framing   │ │ TLS JA3 Spoofer │
└──────────────┘ └──────────────┘ └─────────────────┘
```

### Module Specifications:
1. **`proxy-engine.wsm`**: High-performance packet mutator, CORS stripper, and client-side header neutralizer.
2. **`tunnel-core.wsm`**: Multiplexed WebSocket protocol framing, payload packing, and TCP keepalive heartbeat manager.
3. **`stealth-crypto.wsm`**: Zero-knowledge payload encryption and dynamic TLS JA3 fingerprint emulator.

## 🔐 07. NOVAAC ARCHIVE MATRIX

NovaAc is Spotui’s custom structured audio archive standard. Spotui Web v3.0 supports **framed Web Passphrase** specifications:

| Archive Format | Web Platform Status | Cryptographic Specification |
| :--- | :---: | :--- |
| **Web Passphrase (Framed v7)** | `SUPPORTED` | PBKDF2-HMAC-SHA256 derivation with independently authenticated AES-GCM payload frames. |
| **Web Passphrase (Framed v8)** | `SUPPORTED` | Authenticated frame headers, chunk indices, and bounded-memory streaming decompression. |
| **Android Device-Secure (Keystore)** | `UNSUPPORTED` | *Incompatible by design.* Locked to native Android Keystore hardware chips; cannot derive in browser. |
| **Legacy Monolithic Archives** | `NOT RECOMMENDED` | Exceeds web worker single-buffer allocation limits on large file sets. |

## 🚀 08. QUICK START & LOCAL SETUP

### Prerequisites
- **Node.js**: v18.0.0+ (v20+ LTS recommended)
- **Package Manager**: `npm`, `pnpm`, or `yarn`

```bash
# 1. Clone the updated Project 3.0 repository
git clone https://github.com/lfisher447-afk/project-3.0-the-3rd-ig.git
cd project-3.0-the-3rd-ig

# 2. Install dependencies
npm install

# 3. Compile the .wsm WebAssembly binaries
node scripts/build-wsm.js

# 4. Start local development server (binds to http://localhost:3000)
npm run dev

# 5. Build for production
npm run build
```

## 🔒 10. SECURITY & ZERO-KNOWLEDGE ARCHITECTURE

- **Zero Remote Passphrase Storage**: Passphrases and decryption keys are evaluated inside ephemeral Web Crypto memory buffers and never transmitted over the wire.
- **Client-Side File Isolation**: Tracks selected from local disk stay inside your browser sandbox and are never uploaded to any central server.
- **IndexedDB User Control**: All persistent audio catalogs, offline metadata, and cache records remain local to your browser profile. They can be purged with a single click inside the **System Deck**.
- **No DRM Circumvention**: Spotui Web does not bypass digital rights management for protected commercial streams.
